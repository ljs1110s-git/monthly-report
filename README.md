# monthly-report

월간 보고서 PDF를 확인하고 업로드하는 간단한 Flask 앱입니다.

## 실행

```bash
pip install -r requirements.txt
python app.py
```

브라우저에서 `http://127.0.0.1:5000`으로 접속합니다.

## 연도별 보고서

- 2026년부터 연도별로 묶고 최신 연도 목록을 펼쳐 표시합니다.
- 업로드할 때 보고서 연도와 월을 선택합니다. 여러 파일은 같은 연도·월로 등록됩니다.
- 연도 안에서는 최근 업로드한 보고서를 먼저 표시합니다.
- 기존 파일명에 `제2026-10호` 또는 `2026년 10월`과 같은 표기가 있으면 자동 분류합니다.
- 확인할 수 없는 파일은 `연도·월 미확인`에 표시합니다. 각 보고서의 연도·월 수정 버튼에서 관리자 비밀번호로 분류를 변경할 수 있습니다.
- 원래 PDF 파일명은 유지하며, 분류 정보는 같은 폴더의 `<파일명>.metadata.json`에 저장합니다. 백업·복원할 때 PDF와 분류 정보 파일을 함께 보존해야 합니다.
